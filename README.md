# desk-3d

A slowly spinning 3D desk you can orbit in the browser, built with React, Vite and react-three-fiber.

**Live:** https://roiyot26.github.io/desk-3d/

![Desk 3D screenshot](docs/screenshot.png)

## Run locally

```bash
npm i
npm run dev
```

## The model

`public/desk.glb` is exported from a Blender script. Swap in any glTF/GLB at `public/desk.glb` and the page will load, center and frame it automatically.
